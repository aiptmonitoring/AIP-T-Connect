# AIP&T backend

This folder owns the Supabase backend independently of the frontend.

## Contents

- `supabase/migrations/` — versioned Postgres schema and RLS policies.
- `supabase/functions/` — privileged Edge Functions, such as admin provisioning and signed S3 URL generation.
- `supabase/seed.sql` — non-production sample data when approved.
- `.env` — local secrets (never commit this file).

## Project image storage

Project images use the same private, pre-created Amazon S3 bucket as the other
document functions: `aiptuploaddocument`. The Projects Edge
Function does not create or configure the bucket at request time, so its IAM
identity does not need `s3:CreateBucket`, `s3:HeadBucket`, or bucket-policy
permissions. Configure the bucket once in AWS with Block Public Access and
default encryption enabled, then set the following Supabase Edge Function
secrets: `AWS_REGION`, `AWS_S3_BUCKET`, `AWS_ACCESS_KEY_ID`, and
`AWS_SECRET_ACCESS_KEY`.

The same IAM identity may be reused by all S3 Edge Functions. Its policy must
allow the project image object actions below. Keep the other prefixes only if
the Notifications and Timelines functions use this same bucket:

```json
{
	"Version": "2012-10-17",
	"Statement": [
		{
			"Effect": "Allow",
			"Action": ["s3:PutObject", "s3:GetObject"],
			"Resource": "arn:aws:s3:::aiptuploaddocument/projects/images/*"
		},
		{
			"Effect": "Allow",
			"Action": ["s3:PutObject", "s3:GetObject", "s3:DeleteObject"],
			"Resource": [
				"arn:aws:s3:::aiptuploaddocument/notifications/*",
				"arn:aws:s3:::aiptuploaddocument/notifications/timelines/*",
				"arn:aws:s3:::aiptuploaddocument/statements/*"
			]
		}
	]
}
```

The bucket must already exist in the same region as `AWS_REGION`. Signed GET
URLs are generated by the Projects Function and expire after five minutes.

The admin and client POA pages read documents from `aiptPOA/`. Configure the
`poa` Edge Function with the same S3 secrets and keep the bucket private. It
requires `s3:ListBucket` on the bucket and `s3:GetObject`, `s3:PutObject`, and
`s3:DeleteObject` on `arn:aws:s3:::aiptuploaddocument/aiptPOA/*`. Admin uploads
allow PDF, DOC, and DOCX files up to 10 MB.

Each newly managed POA is stored as one S3 object. Its country associations are
stored in `poa_documents` and `poa_document_countries`; a single object can be
linked to any number of active countries. An empty association list means
“All Countries”. The `save_poa_document` database function updates the document
and its country links atomically. The POA Edge Function preserves access to
older country-folder objects and the shared `Client Design Proposal.docx`
object while they are migrated through normal administrator edits.

The `schedule-of-fees` Edge Function backs the admin-only `/schedule-of-fees`
page. It uses the same bucket and AWS secrets, with `s3:ListBucket` on the
bucket and `s3:GetObject`, `s3:PutObject`, and `s3:DeleteObject` on
`arn:aws:s3:::aiptuploaddocument/aiptschedule_of_fees/*`. Add this object scope
to the IAM identity used by the functions. Schedule documents can be PDF,
Excel (`.xls`, `.xlsx`), or Word (`.doc`, `.docx`) files up to 25 MB.

Add this statement to the existing IAM policy (which already grants
`s3:ListBucket` on the bucket):

```json
{
  "Sid": "ScheduleOfFeesAccess",
  "Effect": "Allow",
  "Action": ["s3:PutObject", "s3:GetObject", "s3:DeleteObject"],
  "Resource": "arn:aws:s3:::aiptuploaddocument/aiptschedule_of_fees/*"
}
```

The shared storage helper requires explicit `AWS_S3_BUCKET` and `AWS_REGION`
secrets and never falls back to another bucket. The configured target is
`aiptuploaddocument` in `eu-north-1`. POA and Schedule of Fees retain their
separate prefixes above. See `aws/admin-documents-policy.json` for an additive
IAM policy limited to these folders. Attach it to the identity used by the
Edge Function AWS credentials; existing policies and permission boundaries
can still deny operations. S3 permission details: https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-with-s3-policy-actions.html

Validation commands:

- `node ../frontend/scripts/admin-documents-regression.cjs`: isolated backend CRUD and failure cases.
- `node ../frontend/scripts/admin-documents-browser-check.cjs`: synthetic administrator browser flows against port 3104.
- `node scripts/check-admin-documents.mjs`: live CRUD using only uniquely named test files, which are deleted afterward; it creates a temporary session for the configured test administrator without sending email or changing passwords.

Apply `202610030001_create_poa_documents.sql` and deploy `poa` and
`schedule-of-fees` when setting up a new environment.

Set the same values as Supabase Edge Function secrets for `projects`,
`notifications`, and `timelines`; local `.env` values are not deployed
automatically. Never place these credentials in frontend code.

Copy `.env.example` to `.env` and supply real values only in your local environment or deployment secret store. In particular, `SUPABASE_SERVICE_ROLE_KEY` must never be copied to `frontend/`.

The POA schema and save function are defined in
`supabase/migrations/202610030001_create_poa_documents.sql`; apply this migration
before deploying the updated POA Edge Function.

## Admin fees from Google Sheets

The `fees` Edge Function reads the fee sheet server-side and enriches each row
with the active Country, Procedure, and Service records from Supabase. It only
accepts administrator sessions and never exposes the service-account key to the
frontend.

Configure these Supabase Edge Function secrets before deploying `fees`:

```text
GOOGLE_SHEETS_SPREADSHEET_ID=1Q5iVUCqE7-EqLzNj5iCySt4kITGijk3V37kpWugGNFw
GOOGLE_SHEETS_RANGE=Fees!A:ZZ
GOOGLE_SHEETS_CLASSES_RANGE=Classes!A:ZZ
GOOGLE_SERVICE_ACCOUNT_JSON=<the complete service-account JSON object>
```

Enable the Google Sheets API, share the spreadsheet with the service-account
`client_email` as a Viewer, and keep the JSON key only in the secret store.
The configured range must include the two header rows used by the fee matrix:
procedure names in the first row and `Official Fees`, `Attorney Fees`, and
`TOTAL` subheaders in the second row. The function calculates missing totals
and resolves each procedure's service from the database.

The admin page is available at `/fees`. It currently provides read-only sheet
display, service filtering, country search, pagination, and refresh. Editing,
deleting, and writing back to Sheets are intentionally not enabled until the
sheet ownership and write contract are confirmed.
